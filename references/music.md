# 原创配乐与独立工作台

配乐先建立主题、和声、段落与声音层次，再与画面共用秒数时间轴。已有旁白、音乐和音效的拼接仍用 [混音工具](audio.md#多素材混音)。本工作台提供可复现的原创器乐草稿，不调用在线服务，不含商业录音或知名歌曲片段。

## 直接试听

双击技能中的 `workbench/index.html`。页面自带三种方向：叙事电影、温暖讲述、精密电子。默认使用多音区采样钢琴、弦乐与贝斯；电子方向保留合成拨弦和鼓组。可切换“轻量合成”听同一编排的音色差异。左侧可调整速度、片长、调性、推进强度、动机变化与空间感，也可编辑 3–8 个主题音级和种子。种子控制细微演奏差异，不作为提升音乐质量的主要手段。

- 乐谱显示主题与和声的实际音符，段落显示实际编排位置，波形在生成后根据实际 PCM 绘制。
- A/B 使用同一主题与种子。A 保留重复主题，B 在中段减少完整主题，只保留片段，在重点与结尾再现，并加入移位、节奏和尾句变化；和声与配器仍保留，不将 A 描述为未经处理的原始录音。
- 六个分轨为主题、和声、低音、织体、节奏、空间。音量、M 静音和 S 独听即时生效；导出 WAV 使用当前混音。空间轨是合成音轨的延迟反射。
- 选择段落并打开循环，集中试听转场或主题变化。点击乐谱、波形或拖动进度定位。
- 可导入本地视频，同步播放、暂停和定位；原声默认静音，可单独打开试听音画及旁白关系。视频文件仅在本机打开。
- 保存方案 JSON、导出 WAV、MIDI 和时间轴 JS。重新载入方案可复现同一乐谱；参数改变后需重新生成声音。WAV 默认 44.1kHz 双声道 PCM，MIDI 可交给音源或编曲软件继续制作。

工作台不要求先生成视频，试听也不触发 MP4 导出。先让用户确认音乐，再接入画面并确认整体 HTML。

## 新建独立工作台

```bash
node scripts/music.mjs init output/my-score --preset cinema --duration 32
```

复制可独立移动的工作台文件，不覆盖已有目录。`--preset` 接受 `cinema/warm/pulse`；还可传 `--bpm`、`--key 0…11` 和 `--mode minor/major/dorian`。新页面的 `score-config.js` 保存初始方案，无需 HTTP 或 npm 依赖。

## 将确认的方案接入视频

从工作台保存 `score.json`，然后：

```bash
node scripts/music.mjs render path/to/score.json --out path/to/my-video/assets/score.wav
```

命令行使用同一乐谱与音色引擎，输出 48kHz 双声道 WAV、方案 JSON、`score.mid`、`score.timeline.js` 和 `score.credits.txt`，拒绝覆盖已有产物。WAV 同时嵌入采样署名。浏览器导出与 CLI 的采样率不同，乐谱与配器相同，逐样本哈希不相同；在同一采样率、方案和实现下可以复现。采样引擎使用固定的整曲 RMS 电平补偿与软限幅，实时播放和文件输出共用补偿；这不等于 LUFS 归一化，最终仍需试听音量。

项目中写 `audio: { src: 'assets/score.wav' }`。若需要和旁白混音，把生成音轨作为 `role: 'music'` 接入 `mix-audio.mjs`，生成最终 master 并更新 `audio.src`。工作台原声试听不等于已生成旁白混音文件。

将 `score.timeline.js` 在 `project.js` 前按普通 script 加载，可读取 `window.MUSIC_TIMELINE.bpm/beat/bar/sections/cues/phrases`，安排画面切点、重音和主题回归。不能为踩点强行压缩文字阅读时间。

## 配乐设计判断

1. **主题可识别**：从一个短动机起步，保留节奏或音程轮廓，让重复、回答和回归可被听出。变化承担叙事作用，避免每一段都换掉主体。
2. **和声连接自然**：通过和弦转位寻找相邻声部位置；低音明确基础，给主题保留音域。
3. **段落有取舍**：铺陈减少元素，展开增加信息，推进提高密度，收束撤去鼓组并回归主和弦。短片不必机械保留全部四段。
4. **为内容留白**：有旁白时减弱主题与高频织体，优先保证台词可懂；必要时调整段落和音符密度，再用混音工具做配乐避让。
5. **听完整收尾**：检查开头是否突兀、末尾是否自然结束、重音是否喧宾夺主。峰值保护不等同于适合发布的整体响度。

本地音色引擎适合比较作曲与编排方向；MIDI 保留音符、速度与分轨，可使用更精细的采样音源继续制作，音色和空间效果不随 MIDI 自动迁移。钢琴来自 Alexander Holm 的 Salamander Grand Piano；弦乐与贝斯来自 Frank Wen 的 FluidR3 GM，由 MIDI.js Soundfonts 预渲染，均按 CC BY 3.0 署名。具体处理和源文件哈希见 `workbench/sample-bank.js.sources.json`，完整署名见 `workbench/SAMPLES-LICENSE.txt`。复制工作台时必须保留音色库和署名。
